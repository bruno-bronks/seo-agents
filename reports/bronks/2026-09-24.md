## Top 3 Ações Imediatas

### 1. CRÍTICO — Resolver indexação SPA (esta semana, impacto em tudo)

**Situação atual:** `site:bronks.ia.br` retorna apenas 1 URL pelo 4º dia consecutivo monitorado.  
**Diagnóstico provável:** Framework JavaScript (React/Vue/Next?) sem SSR ou pré-renderização. O Googlebot não consegue executar JavaScript suficientemente para descobrir sub-páginas.  
**Ação concreta:**
- Confirmar qual framework o site usa (verificar código-fonte ou package.json do repo)
- Se Next.js: ativar `getStaticProps` ou `getServerSideProps` em todas as páginas
- Se React SPA puro: migrar para Next.js com geração estática (SSG)
- Criar `sitemap.xml` com todas as URLs do site
- Submeter sitemap no Google Search Console
- Verificar `/robots.txt` para garantir que não bloqueia CSS/JS/imagens

**Por que é urgente:** Sem resolver isso, NENHUM conteúdo novo criado será indexado. É o bloqueador raiz.
